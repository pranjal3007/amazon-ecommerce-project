# 🛒 Amazon E-commerce Data Analysis

An end-to-end **Data Analytics project** focused on analyzing Amazon e-commerce data to understand sales performance, customer behavior, inventory, seller performance, pricing, ratings, returns, and delivery trends.

The project combines **SQL, Python, Excel, and Power BI** to transform raw e-commerce data into meaningful business insights and interactive dashboards.

---

## 📌 Project Overview

E-commerce platforms generate large volumes of transactional, customer, product, seller, and delivery data.

The objective of this project is to analyze Amazon e-commerce data and answer important business questions such as:

* Which products and categories generate the most revenue?
* How are sellers performing?
* What factors affect product sales?
* What does customer purchasing behavior look like?
* Which products have higher return rates?
* How do price and ratings relate to product performance?
* What are the major inventory and delivery patterns?
* Which areas require attention from a business perspective?

---

## 🎯 Project Objectives

* Clean and prepare raw e-commerce data for analysis.
* Perform exploratory data analysis using Python.
* Write SQL queries to answer business questions.
* Analyze sales, products, customers, sellers, inventory, and delivery data.
* Build an interactive Power BI dashboard.
* Identify meaningful trends and patterns.
* Present findings through visualizations suitable for business decision-making.
